# Database Lock Readiness Checklist

- [ ] All expected subjects accounted for
- [ ] CRF forms complete or appropriately documented as missing
- [ ] Critical edit checks executed
- [ ] Open data queries reviewed and resolved/justified
- [ ] Adverse-event data reconciled
- [ ] Laboratory data reviewed/reconciled
- [ ] Coding completed and reviewed where applicable
- [ ] Protocol deviations reviewed
- [ ] Data cleaning log finalized
- [ ] SDTM mapping reviewed
- [ ] Final data transfer specifications confirmed
- [ ] No unexplained discrepancies remain
- [ ] Database lock approval documented

**Training note:** This checklist is illustrative and not a validated sponsor database-lock SOP.
